# Developer preview announcement draft

Draft only. Do not post until the package release, tag and mandatory framework/package/account/host gates are complete and the maintainer selects the audience/channel. Live model evaluation is optional.

IntentBlazor is an MIT-licensed Blazor framework built around AiInput and AiOutput. Developers expose authorized C# data and actions; the model proposes a versioned document and the deterministic renderer turns it into an interactive workspace. Direct edits, selections, registered actions, bounded content adapters, renderer packs and optional persistence share the same runtime.

The repository includes a two-component quickstart, documentation and three synthetic applications: Gaming News, Staff Business and Asset Workbench. We welcome focused contributions to output fixtures, keyboard/accessibility behavior, provider capability reports, docs, content adapters and renderer packs. Start with the contribution guide and discuss public contract changes before implementation.

At publication, insert the actual tagged source, package versions, implemented adapter capabilities, any optional observed provider profiles, public docs URL and remaining limits. Do not claim live certification without evidence. The APIs and output schemas remain experimental; WASM/Hybrid and distributed persistence are future compatibility work.
