# Project identity and open-source model

Status: accepted October 29, 2026.

The project name is IntentBlazor. The GitHub repository is Kita72/IntentBlazor and the namespace/package prefix is IntentBlazor. Tory selected the name after initial GitHub and exact NuGet name checks. Those checks are not trademark clearance or package reservation.

The code and project documentation use MIT, with copyright held by Tory Bertram and contributors. Contributor submissions follow the project license without a separate CLA. Sample assets require independent rights and attribution.

Use one public repository for contracts, runtime, renderers, docs, examples, and contributor discussion. Tory is the initial maintainer; additional maintainers are added through the governance process.

Public NuGet publication and public hosted model access remain later release work. Publishing the source does not declare the framework production ready.
