# Game Asset Workbench example

Planned for Phase 5. No application is implemented in this directory yet.

Demonstrate image import, metadata, zoomable preview, one deterministic transformation, recoverable versions, and PNG export. Use original or redistribution-compatible sample assets with recorded rights.

Acceptance: import, select, adjust, compare, recover an earlier version, and export the displayed working artifact. A chat model connection does not imply image-generation capability.
