# IntentBlazor.AssetWorkbench

Interactivity Mode: Server. Interactivity Scope: Per-page. Created with dotnet new blazor -int Server --empty.

Pages are static SSR by default. The workspace uses InteractiveServer with prerender disabled; keep Routes static. Sign-in uses static SSR and antiforgery-protected HTTP POSTs. Interactive code uses AuthenticationStateProvider, never HttpContext. Use private content delivery and immutable originals through public APIs. Procedural sample pixels are original MIT assets. A chat model does not imply image generation. Keep domain behavior here and retain AiInput/AiOutput.
