# Output document specification

Phase 1 will define the canonical C# and JSON contracts here. The examples in the implementation plan are design sketches, not supported schemas.

Required subjects: schema versions, toolkit requirements, document revisions, dataset and artifact references, typed state, view nodes, restricted bindings, validated events, action results, dirty-field conflicts, and restoration.

Before accepting a schema, represent the news reader, staff assignment, and asset gallery using the same mechanisms. See [the output architecture decision](../../docs/architecture/0003-output-and-authority.md).
