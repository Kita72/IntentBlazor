# Output schema 0.3: content and renderer extensions

Status: implemented experimental addition to [0.1](README.md) and [0.2 actions](v0.2-actions.md). Builtin toolkit remains `0.1`. Old documents retain their original behavior. The canonical contracts and validator live in [Core](../../src/IntentBlazor.Core).

| Node | Required members / behavior |
| --- | --- |
| markdown | Label and text `value`; headings, paragraphs and bullet blocks, with encoded HTML. |
| chart | Label, host `dataSetId`, and `chart:{kind,labelField,valueField}`. Kind is bar or line; at most 50 labelled numeric rows, values between -1e9 and 1e9. A data table provides a textual alternative. |
| gallery | Label, host `dataSetId`, `labelField`, and `imageField`. Images must use allowed application-local URLs; optional selection uses the same interaction contract as lists/tables. |
| artifact | Label and `value` naming an attached artifact ID. The content service reauthorizes metadata; authenticated delivery separately checks the current request identity. |
| extension | Label and `extension:{pack,version,renderer,configuration,fallback}`. Only host-registered component types can render it. |

Extension configurations are objects bounded to 8,192 characters; fallbacks are nonempty encoded text up to 500 characters. Pack/renderer identifiers follow the ordinary identifier rules. Versions are exact bounded tokens. Configuration validation belongs to the registered typed contract. Ordinary children are permitted for installed extensions, preserving the single rooted tree and its limits.

An image editor node can be represented as:

~~~json
{
  "id": "editor",
  "kind": "extension",
  "title": "Image preview and resize",
  "whenState": "isImage",
  "children": ["width", "height", "resize"],
  "extension": {
    "pack": "images",
    "version": "0.1",
    "renderer": "editor",
    "configuration": {
      "originalState": "selectedArtifact",
      "previewState": "previewArtifact",
      "comparisonState": "showOriginal"
    },
    "fallback": "The image editor is unavailable. Download the original to continue."
  }
}
~~~

This fragment assumes the matching record-reference/boolean state and child nodes. The complete executable example is [ImageEditorDocuments.cs](../../src/IntentBlazor.Packs.ImageEditor/ImageEditorDocuments.cs). Its resize button uses the ordinary registered application-action contract with an immutable source version. The action returns validated state/data plus newly created artifact references; only an actual successful result acknowledges the edited dimensions.

If the pack is essential, declare `"images":"0.1"` in `requires`. Missing/incompatible required packs reject the proposal and preserve the current workspace. An unavailable optional extension can render only its text fallback and must have no interactive children. A node cannot contradict the version declared for its required pack.

Typed local extension events carry node identity and expected session revision. The runtime bounds their JSON payload to 4,096 characters and their effects to 16 unique declared state targets. It rejects hidden/stale/unavailable sources, invalid types/ranges, malformed effects, and non-draft effects that would overwrite a dirty field. Compatible registered editors participate in follow-up dirty-field preservation. These events cannot call an application write handler.

The model receives registered descriptor/configuration examples and content metadata/excerpts. It supplies presentation only; host-authorized datasets and artifact handles remain outside its authority. No arbitrary type loading, URL fetching, expression evaluation, dynamic Razor compilation, or generated executable scripts are introduced.
